### Download

#### Linux
```bash
curl -sSL https://github.com/Bakminstof/pki-chain-builder/raw/refs/heads/release/scripts/linux/get-repo.sh | bash
```

#### Windows
```bash
curl -sSL https://github.com/Bakminstof/pki-chain-builder/raw/refs/heads/release/scripts/win/get-repo.cmd | cmd -c
```

### Use Linux
```bash
cd pki-chain-builder
./scripts/linux/run-pki-builder.sh
```
### Use Windows
```bash
cd pki-chain-builder/scripts/win
run-pki-builder.cmd
```
